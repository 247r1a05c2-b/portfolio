# Shaik Irfan Hussain — Portfolio

## Requirements
- Node.js 18 or higher
- npm or pnpm

## Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Then open http://localhost:5173 in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

The built files will be in the `dist/` folder — you can host them on any static server (Netlify, Vercel, GitHub Pages, etc.).
